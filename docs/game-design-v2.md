# 谁是 AI — 游戏设计文档 v2.0

> 版本：2026-04-11
> 状态：待实施

---

## 一、核心概念

### 1.1 一句话定义

> 一个「按钮点击 + 行为推理 + 多阵营博弈」的社交对抗游戏。玩家通过回答梗题、表达反应、当面对质来暴露自己或隐藏自己，目标是找出隐藏在人群中的 AI。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 好上手 | 全程点击按钮，不需要打字 |
| 有斗智 | 多阵营博弈，玩家之间有对抗 |
| 有梗 | 题目和场景符合年轻互联网文化 |
| 快节奏 | 4-8 分钟一局，3 轮决胜 |
| 有反转 | 不到最后不知道谁赢 |

## 二、角色系统

### 2.1 四种角色

| 角色 | 阵营 | 目标 | 身份 |
|------|------|------|------|
| **侦探** | 侦探阵营（团队） | 找出并投票淘汰 AI | 公开 |
| **AI** | AI 阵营（系统） | 存活到最后 | 隐藏 |
| **叛徒** | AI 阵营（隐藏） | 帮助 AI 存活，不暴露自己 | 隐藏 |
| **狱卒** | 个人阵营（独自） | 用审讯能力锁定 AI，独自获胜 | 公开 |

### 2.2 阵营关系

```
侦探阵营（团队胜利）：
  侦探们合作投票淘汰 AI

AI 阵营（团队胜利）：
  AI + 叛徒配合，让 AI 存活到终局

个人胜利：
  狱卒用审讯锁定 AI → 狱卒一个人赢，其他所有人输
```

**核心博弈点：侦探和狱卒都想抓 AI，但狱卒想独赢。狱卒的存在让「好人阵营」内部也产生猜疑。**

### 2.3 不同人数的配置

| 人数 | 侦探 | AI | 叛徒 | 狱卒 | 轮数 | 预计时长 |
|------|------|----|------|------|------|----------|
| 4 人 | 2 | 1 | 0 | 1 | 2 轮 | 3-4 分钟 |
| 5 人 | 3 | 1 | 0 | 1 | 2 轮 | 4-5 分钟 |
| 6 人 | 3 | 1 | 1 | 1 | 3 轮 | 5-6 分钟 |
| 7 人 | 4 | 1 | 1 | 1 | 3 轮 | 6-7 分钟 |
| 8 人 | 5 | 1 | 1 | 1 | 3 轮 | 7-8 分钟 |

**规则：叛徒只在 6 人及以上出现。人少时「好人内部猜疑」靠狱卒就够了。**

### 2.4 角色分配

**分配方式：系统随机分配，玩家在开局前不知道自己是什么角色。**

```
分配流程：
  1. 所有玩家进入房间
  2. 系统随机指定 1 人 → AI
  3. 系统随机指定 1 人 → 狱卒（公开身份，所有人知道谁是狱卒）
  4. 6 人及以上：系统随机指定 1 人 → 叛徒（隐藏身份）
  5. 其余所有人 → 侦探
  6. AI 和叛徒互相知道对方身份
  7. 其他所有人只知道自己的角色
```

**为什么狱卒身份公开：** 狱卒公开身份后，所有人都知道「有一个人在单独调查」，这本身就制造了博弈——狱卒的信息可信吗？他会不会撒谎？如果狱卒隐藏身份，这个博弈就不存在了。

### 2.5 角色能力

#### 侦探
- **暗查**（每轮 1 次）：选择一个玩家，秘密查看他本轮某一道题的选择（只有自己看到）
  - 这是侦探唯一的私密信息来源，让侦探也有「我知道但别人不知道」的推理优势
- 每轮可以参与公共令牌讨论和个人筹码押注
- 靠行为数据分析和团队投票来抓 AI

#### AI（系统角色）
- 自动回答直觉测试题（倾向选「安全选项」）
- 自动选择共感反应（倾向选「中性表情」）
- 被审讯时自动回应（回应有破绽但不会明显到一眼看出）
- AI 的破绽分布：普通级 80% 有线索，高级 50%，间谍级 25%

#### 叛徒
- 知道谁是 AI（AI 也知道谁是叛徒）
- 目标是帮 AI 存活：投票投别人、引导令牌浪费、在对质时帮 AI 说话
- 行为要像正常侦探，不能太明显地保护某个人
- 被投票出局时身份公开（显示「叛徒」）

#### 狱卒
- 每轮可以执行一次「审讯」
- 审讯是 1v1 封闭问答，只有狱卒看到结果
- 审讯到 AI → AI 回答有破绽，狱卒获得线索
- 审讯到真人 → 真人回答自然，狱卒排除嫌疑
- 狱卒可以选择公开、隐藏或撒谎审讯结果
- 狱卒可以独自「锁定」目标（需消耗 1 轮审讯结果）→ 锁定正确则独赢

## 三、核心玩法流程

### 3.1 单轮结构（总时长约 2 分钟）

```
┌─ 第一阶段：行动（60秒）──────────────────────────┐
│                                                   │
│  1a. 直觉测试（15秒 × 3题 = 45秒）                 │
│      - 3 道梗题，每题四选一，同时作答               │
│      - 答案自动生成行为数据矩阵                     │
│                                                   │
│  1b. 共感反应（15秒 × 1个场景）                    │
│      - 1 个场景，同时选表情反应                     │
│      - 反应暴露性格倾向                             │
│                                                   │
│  1c. 侦探暗查（穿插在行动中）                       │
│      - 每个侦探可以选择查看 1 人的 1 道题答案        │
│      - 结果只有自己看到                             │
│                                                   │
└───────────────────────────────────────────────────┘
                    ↓
┌─ 第二阶段：博弈（50秒）──────────────────────────┐
│                                                   │
│  2a. 狱卒审讯（15秒）                              │
│      - 狱卒选择审讯目标，提出封闭式问题              │
│      - 被审者必须回答                              │
│      - 结果只有狱卒看到                             │
│                                                   │
│  2b. 公共令牌讨论（20秒）                          │
│      - 全队可见的聊天窗口（简短文字或预设选项）       │
│      - 讨论怎么花 3 个公共令牌                      │
│      - 投票决定是否使用、用在谁身上                  │
│      - 令牌效果在投票前生效                         │
│                                                   │
│  2c. 个人筹码押注（15秒）                          │
│      - 每人秘密押注 1 个信任的人                    │
│      - 筹码分布在投票后公开                         │
│                                                   │
└───────────────────────────────────────────────────┘
                    ↓
┌─ 第三阶段：对质投票（50秒）──────────────────────┐
│                                                   │
│  3a. 系统提名（5秒）                               │
│      - 根据行为数据，提名最可疑的 1-2 人            │
│      - 提名理由公开（「连续选安全选项」「反应最平淡」）│
│                                                   │
│  3b. 被提名者回应（15秒）                          │
│      - 被提名者从预设选项中选择回应                  │
│      - 回应选项及效果：                             │
│        [反击] → 指向另一个嫌疑人，转移焦点          │
│        [解释] → 说明自己的选择逻辑                  │
│        [反问] → 质疑指控者的动机                    │
│        [沉默] → 不回应，节省时间但增加嫌疑值        │
│      - 回应效果：影响全队的「怀疑度」权重            │
│                                                   │
│  3c. 最终陈述（10秒）                              │
│      - 被提名者和得票第二的人各说一句话              │
│      - 可选预设台词，也可自定义简短输入（10字以内）   │
│                                                   │
│  3d. 全员投票（20秒）                              │
│      - 所有人投票淘汰一人                           │
│      - 个人筹码加成生效（×2 或 ×0.5）              │
│      - 得票最多者出局，身份公开                     │
│      - 若平票 → 平票者进入 30 秒加赛对质            │
│                                                   │
└───────────────────────────────────────────────────┘
```

**各角色在每轮中的行动汇总：**

| 角色 | 第一阶段（行动） | 第二阶段（博弈） | 第三阶段（对质投票） |
|------|-----------------|-----------------|---------------------|
| 侦探 | 答题 + 反应 + 暗查 | 参与讨论 + 押筹码 | 回应（若被提名）+ 投票 |
| AI | 答题 + 反应（自动） | 参与讨论 + 押筹码 | 回应（若被提名）+ 投票 |
| 叛徒 | 答题 + 反应 | 引导讨论 + 押筹码（帮AI）| 回应（若被提名）+ 投票（投别人）|
| 狱卒 | 答题 + 反应 | 审讯 + 参与讨论 + 押筹码 | 回应（若被提名）+ 投票 |

### 3.2 完整对局流程

```
第一轮（N 人）→ 投出 1 人 → 剩 N-1 人
第二轮（N-1 人）→ 投出 1 人 → 剩 N-2 人
第三轮（N-2 人）→ 投出 1 人 → 剩 N-3 人 → 终局判定
```

不同人数的轮数：
- 4-5 人局：2 轮（剩 2-3 人时终局）
- 6-8 人局：3 轮（剩 3-5 人时终局）

### 3.3 终局判定

```
判定时机：投票结束后，存活人数 ≤ 3 人时触发终局

判定规则（按优先级）：

  情况 1：狱卒在本轮或之前成功锁定 AI
    → 狱卒独自胜利（最高优先级，不论当前局势）
    → 所有其他玩家（包括侦探和 AI）全部失败

  情况 2：存活者中没有 AI（AI 已被投出）
    → 侦探阵营胜利
    → 叛徒已出局 → AI 阵营失败
    → 叛徒仍存活 → 叛徒也失败（没有 AI 可帮了）

  情况 3：存活者中有 AI（AI 存活）
    → AI 阵营胜利
    → 叛徒也胜利（只要 AI 存活，叛徒就赢）

  情况 4：AI 已被投出，但叛徒仍存活
    → 叛徒此时失去阵营目标，变为普通侦探
    → 按侦探阵营规则判定

特殊情况：
  - 狱卒锁定错误 → 狱卒出局，游戏继续
  - 平票 → 平票者进入 30 秒加赛对质后重新投票
  - AI 第 1 轮就被投出 → 剩余轮次中叛徒变普通侦探，游戏变纯侦探 vs 狱卒博弈
```

**平衡性分析：**

| 人数 | AI 阵营占比 | 侦探+狱卒占比 | AI 阵营最低存活轮数 |
|------|------------|--------------|-------------------|
| 4 人 | 1 (25%) | 3 (75%) | 1 轮（第 1 轮不被淘汰） |
| 5 人 | 1 (20%) | 4 (80%) | 2 轮 |
| 6 人 | 2 (33%) | 4 (67%) | 2 轮（叛徒可分散票型） |
| 7 人 | 2 (29%) | 5 (71%) | 3 轮 |
| 8 人 | 2 (25%) | 6 (75%) | 3 轮 |

### 3.4 被淘汰后的体验

```
被淘汰的玩家：
  - 身份立即公开（全场可见：「小红是 AI！」「小王是侦探！」）
  - 进入「上帝视角」观战模式
  - 可以看到：所有存活者的身份标签
  - 可以看到：完整的答题记录、反应记录、投票历史
  - 可以看到：当前筹码分布（投票后公开的）
  - 可以看到：狱卒的审讯历史（仅限出局者可见）
  - 可以发弹幕评论（存活者看不到，观战者之间可见）
  - 可以看到实时排名：「谁判断最准」「谁被骗最惨」
```

## 四、博弈机制

### 4.1 公共令牌（团队资源）

```
全队共享 3 个调查令牌（每局总量，用完不补）

使用方式：
  [窥探] 花 1 令牌 → 投票前偷偷看某人的一道题答案
  [施压] 花 2 令牌 → 强制某人进入对质，必须回应
  [验人] 花 3 令牌 → 查看某人两轮之间的答案是否有矛盾

博弈点：
  - 令牌有限，花完就没了
  - 讨论怎么花本身就是博弈
  - AI/叛徒会提议把令牌浪费在无关紧要的地方
  - 花错了等于帮了 AI
```

### 4.2 个人筹码（个人信任）

```
每人每轮有 1 个信任筹码，押在任意一个人身上

效果：
  ✅ 押的人最终被证明是真人 → 你下一轮投票算 2 票
  ❌ 押的人被证明是 AI/叛徒 → 你下一轮投票算 0.5 票
  🔒 自己留着不押 → 安全，无加成

博弈点：
  - 你想押的人可能正在被全场怀疑
  - 筹码分布本身就是信息
  - AI 可以故意押真人来获取影响力
  - 押错了不仅没加成，还暴露了你的判断力
```

### 4.3 审讯机制（狱卒专属）

```
每轮狱卒可以选择一个目标进行审讯

审讯形式：
  狱卒提出封闭式问题（A 还是 B）
  被审者必须回答

审讯结果：
  - 只有狱卒自己看到
  - 狱卒可以选择：公开 / 隐藏 / 撒谎

博弈点：
  - 狱卒审到了 AI 但不想公开 → 想独赢
  - 侦探质疑狱卒：「你审了什么？为什么不说？」
  - 叛徒挑拨：「狱卒是不是在保护 AI？」
  - 狱卒被团队怀疑时，要不要公开结果来自证？
```

## 五、题目设计

### 5.1 直觉测试题（四选一梗题）

**设计原则：**
- 没有正确答案，四个选项都「正常」但代表不同性格
- 每个选项都有梗，选哪个都能玩
- AI 破绽点：倾向选 B/C「中庸安全」选项，很少选 A/D 极端选项

**题目分类：**

| 类型 | 示例 |
|------|------|
| 风险偏好 | 「半夜饿了你会？」→ 泡面/冰箱剩菜/不吃了/点外卖 |
| 社交反应 | 「室友凌晨开外放」→ 开骂/戴耳机忍了/更大声放歌/发微信阴阳 |
| 情绪反应 | 「对象说需要谈谈」→ 完了完了/该来的总会来/发朋友圈/？我什么时候有的对象 |
| 抽象偏好 | 「给你超能力你选？」→ 飞行/隐身/读心/不用上班 |

**题库规模建议：** 至少 50 道，每局随机抽取。

### 5.2 共感反应场景

**设计原则：**
- 场景要好笑、有共鸣、能引发吐槽
- 表情选项覆盖从温和到极端的完整光谱
- AI 破绽点：倾向选中性表情（🙂😐），很少选极端表情（💀😤🤡）

**场景示例：**

| 场景 | 表情选项 |
|------|----------|
| 「加班到凌晨两点发现公司门锁了」| 😤💀🙂🤡🫠🎯 |
| 「相亲对象是你前任」| 😱😂💀😐🤡🏃 |
| 「外卖被偷了，发现是室友拿的」| 😤🙂🔪💀🤡📢 |

**题库规模建议：** 至少 30 个场景。

### 5.3 对质回应选项

**设计原则：**
- 每个回应代表不同策略：反击/解释/沉默/反问
- 不同角色被对质时的最佳策略不同
- 真人被冤枉会急，AI 被冤枉会「理性解释」（这是一个可识别的破绽）

**回应选项及具体效果：**

| 回应 | 动画表现 | 对投票的影响 | 适合谁用 |
|------|----------|-------------|----------|
| **反击** | 指向另一个玩家 | 被反击者嫌疑值 +15%，反击者嫌疑值 -5% | 叛徒（转移焦点）、被冤枉的真人 |
| **解释** | 冷静分析动画 | 解释者嫌疑值 -10%，但如果解释逻辑有矛盾则 +20% | AI（惯用但有破绽）、真正的侦探 |
| **反问** | 质问动画 | 全场随机一人嫌疑值 +10%，反问者嫌疑值不变 | 狱卒（保持主动）、对抗型人格 |
| **沉默** | 低头不说话 | 沉默者嫌疑值 +25% | 没想好的真人、故意装深沉的 AI |

**AI 在对质中的破绽模式：**
- AI 被指控时更倾向选「解释」（理性分析型回应）
- 真人被指控时更倾向选「反击」或「反问」（情绪驱动的回应）
- AI 极少选「沉默」（程序不会「没想好」）
- 真人选「沉默」时嫌疑值虽然 +25%，但其他玩家会觉得「他可能真的不知道怎么说」

## 六、AI 行为系统

### 6.1 AI 难度分级

| 等级 | 破绽率 | 说明 |
|------|--------|------|
| 普通 | 80% 有线索 | 容易识别，适合新手局 |
| 高级 | 50% 有线索 | 需要仔细分析 |
| 间谍 | 25% 有线索 | 极难识别，适合高手局 |

### 6.2 AI 人格系统

保留现有人格系统，但扩展到新玩法：

| 人格 | 直觉测试倾向 | 共感反应倾向 | 对质回应风格 |
|------|-------------|-------------|-------------|
| 分析型 | 选理性选项 | 选冷静表情 | 逻辑化回应 |
| 谨慎型 | 选安全选项 | 选中性表情 | 留余地的回应 |
| 对抗型 | 选大胆选项 | 选激烈表情 | 反击式回应 |
| 跳脱型 | 选奇葩选项 | 选抽象表情 | 无厘头回应 |

### 6.3 AI 破绽触发

| 环节 | 破绽类型 | 表现 |
|------|----------|------|
| 直觉测试 | 选择安全 | 连续选 B/C，避开极端选项 |
| 共感反应 | 表情平淡 | 倾向 🙂😐，回避 💀😤 |
| 对质 | 过度理性 | 被冤枉时不会「急」，而是冷静分析 |
| 审讯 | 回答破绽 | 审讯中的封闭回答不够自然 |

## 七、观战系统

### 7.1 观战者信息面板

```
被淘汰的玩家进入上帝视角，拥有比在局者更多的信息：

【身份面板】
  存活者：小王（侦探）| 小红（AI）| 小李（狱卒）| 小明（叛徒）
  已出局：你（侦探）| AI_小张（侦探，第 1 轮被投出）

【行为数据面板】（完整版，在局者只能看到自己的）
  小王：A C D B → 选了 4 种，无规律 ✓ 像真人
```

## 附录 B：社交推理游戏设计框架分析

> 综合 Wikipedia、BoardGameGeek 社区、Gamasutra、Game Developer Conference 等多个来源的设计理论，以及经典社交推理游戏（狼人杀、Among Us、Secret Hitler、阿瓦隆、谁是卧底）的机制对比。

### B.1 社交推理游戏的核心定义

社交推理游戏（Social Deduction Game）的本质是：**玩家试图揭露彼此的隐藏角色或阵营归属。** 游戏被分为两个交替的阶段：

1. **私密阶段** — 玩家拥有不对称的信息，通过行动获取或隐藏线索
2. **公开阶段** — 讨论、指控、辩护、投票

成功的游戏在这两个阶段之间创造张力：私密阶段产生信息，公开阶段利用信息制造冲突。

### B.2 四轴评估框架

来自 BoardGameGeek 社区总结的设计评估框架，用于衡量社交推理游戏的机制质量：

| 维度 | 说明 | 评估标准 | 我们的设计 |
|------|------|----------|-----------|
| **信息流** | 公开 vs 私密信息的比例 | 太公开→没有推理空间；太私密→没有讨论依据 | ✅ 行为数据公开，审讯结果私密，令牌使用部分公开 |
| **角色复杂度** | 角色能力的复杂程度 | 太复杂→门槛高；太简单→缺乏深度 | ✅ 4 角色，每个角色只有 1 个核心能力 |
| **胜利条件对齐** | 阵营之间的目标冲突 | 太对称→没有背叛；太不对称→某方无趣 | ✅ 侦探（团队赢）vs 狱卒（个人赢）vs AI+叛徒（团队赢） |
| **淘汰后果** | 出局后玩家的体验 | 无淘汰→没有压力；淘汰后无事做→体验差 | ✅ 出局进入上帝视角观战，有弹幕互动 |

### B.3 六大设计要素

综合多个来源提炼的社交推理游戏成功要素：

```
1. 信息不对称
   谁知道什么，决定了推理的可能性。

   经典案例：
   - 狼人杀：狼人知道彼此，好人不知道
   - Among Us：杀手知道死者，船员不知道
   - 阿瓦隆：梅林知道坏人，但不能暴露自己

   我们的设计：
   - AI 知道谁是叛徒，叛徒知道谁是 AI
   - 狱卒的审讯结果只有自己知道
   - 所有人的行为数据公开，但动机不公开

2. 可控信息释放
   信息不是一次性给完，而是分阶段逐步公开。

   经典案例：
   - 狼人杀：夜晚行动→白天发言→投票，三阶段逐步释放
   - Secret Hitler：法案投票记录逐步积累，形成可分析的模式

   我们的设计：
   - 每轮：答题数据→反应数据→筹码分布→投票结果
   - 三轮之间：前一轮的数据成为下一轮的推理依据
   - 令牌使用记录：谁提议了什么、花在谁身上

3. 有意义的指控机制
   指控不是随口说说，而是有结构、有后果的。

   经典案例：
   - 狼人杀：自由讨论+投票，被投票最多的人出局
   - Among Us：紧急会议，讨论后投票
   - Secret Hitler：通过法案时的投票本身就是指控

   我们的设计：
   - 系统提名（数据驱动）+ 被提名者回应（预设选项）+ 全员投票
   - 对质环节制造 1v1 冲突
   - 投票有后果：淘汰出局，身份公开

4. 角色平衡数学
   不同人数下各阵营的胜率要接近公平。

   经典案例：
   - 狼人杀：4 人 1 狼，8 人 2 狼，12 人 3 狼（约 4:1 比例）
   - Among Us：10 人 2 杀手（5:1 比例）
   - Secret Hitler：5 人 1 希特勒+1 法西斯（自由派多数但信息少）

   我们的设计：
   - 4-8 人配置表已经做过平衡
   - AI 阵营（AI+叛徒）占比：4 人局 25%，6 人局 33%，8 人局 25%
   - 狱卒作为第三阵营，占比固定 1 人（12%-25%）

5. 终局压力设计
   游戏快结束时要有紧张感和戏剧性。

   经典案例：
   - 狼人杀：只剩 3-4 人时，一票定生死
   - Among Us：杀手 vs 船员人数接近时的紧迫感
   - Secret Hitler：希特勒被提名时的最终投票

   我们的设计：
   - 人数递减（6→5→4→3），每一轮投票权重增加
   - 狱卒的锁定可以在任何轮次触发终局
   - 叛徒在最后 3 人时的身份曝光是最大爆点

6. 文化适配
   游戏要符合目标用户的文化习惯和审美。

   经典案例：
   - 狼人杀在中国的成功：社交文化+语言表达能力强
   - Among Us 的全球成功：简单操作+可爱美术+跨语言
   - 谁是卧底的流行：低门槛+词语联想符合中文特点

   我们的设计：
   - 抽象梗题：贴合中国年轻人的互联网文化
   - 表情反应：跨语言的通用表达
   - 零打字：降低语言表达门槛
```

### B.4 经典游戏机制对比

| 游戏 | 信息来源 | 指控方式 | 核心博弈 | 我们可以借鉴 |
|------|----------|----------|----------|-------------|
| **狼人杀** | 夜间行动 + 白天发言 | 自由讨论 + 投票 | 狼人隐藏 vs 预言家查验 | 多角色、淘汰制、投票机制 |
| **Among Us** | 任务完成 + 目击 | 紧急会议 + 讨论 | 杀手伪装 vs 船员目击 | 快节奏、简单操作、视觉证据 |
| **Secret Hitler** | 投票记录 + 法案 | 投票模式分析 | 自由派推理 vs 法西斯伪装 | 行为数据矩阵、累积证据 |
| **阿瓦隆** | 任务成败 + 投票 | 提名 + 任务投票 | 好人推理 vs 坏人干扰 | 阵营信任博弈、信息不对称 |
| **谁是卧底** | 词语描述 | 描述分析 | 间接证据推理 | 间接线索、模糊判断 |

### B.5 关键洞察

**洞察一：行为模式 > 语言内容**

所有成功的社交推理游戏都依赖「行为模式分析」而不是「直接证据」。语言内容容易伪造（AI 也能写出好句子），但行为模式更难伪装（AI 难以自然地改变选择模式）。

我们的设计（答题模式、反应模式、筹码押注模式）恰好符合这个原则。

**洞察二：好人的内部冲突比抓坏人更有趣**

单纯的好人 vs 坏人结构是单调的。增加好人之间的冲突（狱卒想独赢 vs 侦探想团赢）让每一轮都有三层博弈：

```
第一层：谁是 AI？（逻辑推理）
第二层：谁是叛徒？（信任判断）
第三层：狱卒值不值得信任？（阵营判断）
```

**洞察三：消除打字不等于消除表达**

表达不一定要通过打字。选择选项、押注筹码、使用令牌、选择回应——这些「行动」本身就是表达。关键是要让每个行动都有可被分析的信息价值。

**洞察四：淘汰制是社交推理游戏的骨架**

没有淘汰制的游戏缺乏紧迫感。淘汰制创造的「人数递减」让每一轮的投票权重增加，形成天然的叙事弧线（开头轻松→中期紧张→结尾决战）。
