# 谁是AI v3 — 阿瓦隆式社交推理

> 6人局 · 找出渗透者 · 完成3次任务  
> 🤖 AI附身干扰 · 🧠 斗智斗勇

---

## 🎮 游戏规则

### 角色（6人）
- **工程师**（好人）：3名  
  目标：完成3次任务，识别并投票淘汰渗透者
- **渗透者**（坏人）：1名  
  目标：3次任务破坏成功，或隐藏身份不被淘汰
- **信号员**（好人特殊）：1名  
  特殊能力：知道本局是否有 AI 附身，但不知道是谁
- **AI 玩家**（模拟真人）：1名  
  由系统控制，行为随机

### 核心机制

#### AI 附身系统
- 每轮随机 1 名玩家被 AI **附身**（消息被改写）
- 被附身者知道"自己被附身了"，但不知道改写内容
- 信号员知道"本局有附身"，但不知道谁被附身

#### 游戏流程（最多3轮）

每轮 = 4 个阶段：

**① 提名队长**（30秒）  
选择谁带领小队执行任务

**② 受限讨论**（20秒/条 × 3条）  
每人最多说 3 句话，每句 ≤ 30 字  
⚠️ 发言可能被 AI 附身改写

**③ 投票表决**（30秒）  
投票赞成/反对提名  

**④ 执行任务**  
赞成票 ≥ 半数 → 任务执行  
任务执行：小队成员选择 **成功** 或 **破坏**

任务结果判定：
- 成功票 > 破坏票 → 任务成功（好人+1）
- 失败票 ≥ 成功票 → 任务破坏（坏人+1）

**胜利条件**：
- 好人：3 次任务成功
- 坏人：3 次任务破坏

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动服务器
npm run server

# 打开浏览器
# http://localhost:3000
```

### 游戏模式

| 模式 | 人数 | 说明 |
|------|------|------|
| 单人调试 | 1+5AI | 单人练习，AI 自动投票 |
| 测试模式 | 1+5AI | 可跳阶段、加速 |
| 普通模式 | 2-6人 | 真人多人 |
