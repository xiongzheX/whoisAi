# 谁是AI

一个让AI伪装成真人的游戏，真人玩家需要通过对话找出混在人群中的AI。

## 游戏规则

### 流程
```
描述轮 → 提问轮1 → 第一轮投票 → 辩解轮 → 提问轮2 → 最终投票
```

### 详细规则

1. **描述轮**：所有人拿到相同词，每人用一句话描述
2. **提问轮**：自由提问，每人3次机会，可拒绝回答
3. **第一轮投票**：投票选出最可疑的2人
4. **辩解轮**：得票前2名辩解
5. **提问轮2**：继续提问
6. **最终投票**：决定AI是否被找出

### 胜负判定

- **真人胜利**：AI被票出
- **AI胜利**：票出3个真人（⌈6×40%⌉）

## 快速开始

### 1. 安装依赖

```bash
cd 谁是AI
npm install
```

### 2. 启动服务器

```bash
npm run server
```

服务器将在 `http://localhost:3000` 启动

### 3. 访问游戏

在浏览器打开 `http://localhost:3000`

### 4. 多人测试

- 打开多个浏览器窗口
- 每个窗口输入不同名字
- 加入同一个房间（默认 room1）
- 6人自动开始游戏（包含1个AI）

## 技术栈

- **前端**: HTML + CSS + Canvas + Socket.io-client
- **后端**: Node.js + Express + Socket.io
- **AI**: LLM API（可替换为你的AI服务）
