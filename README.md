# 谁是AI v3 — 阿瓦隆式社交推理

> 5-8人局 · 推荐6人 · 找出渗透者 · 完成3次任务  
> 🤖 AI附身干扰 · 🧠 斗智斗勇

---

## 🎮 游戏规则

### 角色（推荐6人）
- **守护者**（守护者阵营）：3名  
  目标：完成3次任务，识别并阻止渗透者
- **渗透者**（渗透者阵营）：1名  
  目标：诱导3次任务失败，并隐藏身份
- **侦测者**（守护者阵营特殊）：1名  
  特殊能力：获得 AI 附身线索，但不知道具体是谁
- **AI 玩家**（模拟真人）：1名  
  由系统控制，行为随机

### 核心机制

#### AI 附身系统
- 每轮随机 1 名玩家被 AI **附身**（消息被改写）
- 被附身者知道"自己被附身了"，但不知道改写内容
- 侦测者知道"本局有附身"，但不知道谁被附身

#### 游戏流程（最多5轮）

每轮 = 4 个阶段：

**① 提名队长**（15秒）  
选择谁带领小队执行任务

**② 受限讨论**（45秒）  
每人最多说 6 句话，每句 ≤ 50 字  
⚠️ 发言可能被 AI 附身改写

**③ 投票表决**（20秒）  
投票赞成/反对提名  

**④ 执行任务**  
赞成票 ≥ 半数 → 任务执行  
任务执行：小队成员围绕危机场景选择行动方案

任务结果判定：
- 小队选择稳妥方案 → 任务成功（守护者+1）
- 小队选择高风险方案 → 任务失败（渗透者+1）

**胜利条件**：
- 守护者阵营：3 次任务成功
- 渗透者阵营：3 次任务失败

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动 Go 服务
GOCACHE=/tmp/whoisai-gocache PORT=3014 go run ./cmd/go-server

# 打开浏览器
# http://localhost:3014
```

### 游戏模式

| 模式 | 人数 | 说明 |
|------|------|------|
| 正常模式 | 5-8人 | 真人好友同房，首位玩家在至少5人到齐后开始 |
| 测试模式 | 1+AI | 自动补 AI 并自动推进，适合快速验证流程 |
| 单人调试 | 1+AI | 单人流程演示，显示调试信息，未接通的跳阶段控制已隐藏 |
